## 3. 布局基调（HIS 风格）

- 顶部深蓝横栏：Logo + 系统名 + 机构切换 + 消息铃铛 + 用户信息
- 左侧白色二级菜单树，可折叠，当前项蓝色高亮
- 工作区多标签页（tabs），浅灰底 + 白色卡片，高信息密度
- 字号：正文 13–14px，表格 13px，紧凑行高

## 4. 交互规范（假设值，待确认）

### 4.1 登录页
- 登录方式：账号（工号/用户名）+ 密码；可选短信验证码页签
- 失败策略：3 次出图形验证码，5 次锁定 30 分钟「假设」
- 记住登录态 7 天「假设」；密码明文切换；回车提交
- 首登强制改密；忘记密码走短信重置「假设」
- 会话超时 30 分钟无操作回登录页「假设」

### 4.2 框架页
- 菜单：展开/折叠记忆、按权限隐藏、面包屑联动
- 多标签页：打开/关闭/关闭其他/固定常用
- 表格：默认 20 条/页、列排序、筛选区可折叠、行 hover、批量操作栏、空态插画
- 表单：必填 `*`、失焦即时校验、保存成功 toast、删除二次确认（危险色）
- 消息中心：角标计数、下拉面板、全部已读、点击预警跳转业务页
- 异常页：401/403/404/500 统一样式

### 4.3 移动端首页
- 授权时序：手机号授权 → 实名引导 → 订阅消息授权；拒绝后有兜底提示
- 首页三态：未实名 / 已实名未签约 / 已签约（本稿按「已签约」主态 + 实名引导条设计）
- 下拉刷新、骨架屏、空态；Toast/ActionSheet/Modal 边界明确
- 底部 5 Tab：首页 / 记录 / 服务 / 消息 / 我的；消息带角标
- 家庭成员切换器置于首页头部

## 5. 账号体系

### 5.1 管理后台（服务提供方）
- 预设角色（投标文件）：超级管理员、机构管理员、科室主任、医生、护士、健康管理师、审核人员
- 凭证：工号/用户名 + 密码；初始密码规则与首登改密「假设：Yd@2026」
- 权限：RBAC，粒度到菜单级、按钮级、数据行级（投标要求）
- 数据范围五级：全平台 / 医共体 / 本机构 / 本科室 / 本人
- 生命周期：创建、编辑、启用/禁用、解锁、密码重置、移除；账号关联医护档案
- 机构归属：账号必挂机构；机构管理员仅管本机构

### 5.2 移动端（服务接受方）
- 登录：手机号 + 短信验证码 / 微信一键获取手机号
- 实名认证：姓名 + 身份证号三方校验（投标要求）
- 状态机：未注册 → 已注册未实名 → 已实名未签约 → 已签约
- 家庭成员：主账号挂成员，代管视角切换、代为签约
- 注销与换号流程

### 5.3 两体系关系
后台账号 ≠ 移动端账号；通过「责任医生绑定」关联。
